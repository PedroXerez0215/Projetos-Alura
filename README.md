# Primeiro Ano da Minha Jornada como Programador

Bem-vindo ao meu repositório!

Este repositório reúne os projetos, exercícios e desafios desenvolvidos durante meu primeiro ano de estudos em programação, utilizando a plataforma **Alura** como fonte de aprendizado.

O objetivo é registrar minha evolução como programador, desde os conceitos fundamentais até tecnologias mais avançadas, mostrando na prática o conhecimento adquirido ao longo da minha formação.

---

## 🎯 Objetivos

- Consolidar os conhecimentos adquiridos nos cursos.
- Desenvolver boas práticas de programação.
- Construir um portfólio que represente minha evolução.
- Compartilhar minha jornada de aprendizado.

## 📁 Organização

Cada pasta deste repositório corresponde a um curso ou formação que concluí ou estarei realizando durante meu primeiro ano de estudos. Dentro de cada uma delas estarão os exercícios, atividades e projetos desenvolvidos ao longo das aulas, registrando minha evolução durante todo o processo de aprendizado.

Sempre que possível, cada projeto contará com:

- 📖 Descrição do projeto
- 🛠️ Tecnologias utilizadas
- 📚 Conceitos aprendidos
- 📸 Imagens ou demonstrações
- 📅 Data de conclusão

---

## 📈 Minha Evolução

Este repositório será atualizado continuamente durante meu primeiro ano de estudos.

Meu objetivo é que, ao final dessa jornada, ele represente toda a minha evolução como desenvolvedor e sirva como um portfólio da minha trajetória na programação.
